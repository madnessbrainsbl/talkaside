# Talkaside: 면접 AI 도우미와 실시간 통화 번역

**[talkaside.com](https://talkaside.com/)** · Windows 10/11 · 5일 무료 데모

Talkaside는 PC에서 진행되는 통화를 실시간으로 듣고, 양쪽의 말을 하는 즉시 텍스트로 옮깁니다. 그리고 두 가지를 바로 알려 드립니다. 누군가 질문하면 답변 초안을, 상대가 내가 모르는 언어로 말하면 번역을 보여 줍니다. Windows에서 오디오를 직접 가져오기 때문에 평소 쓰는 통화 앱을 그대로 사용할 수 있습니다.

## 주요 기능

**면접 중 답변 제안.** AI 어시스턴트 두 개가 실시간 대화 기록, 이력서, 채용 공고, 직접 만든 Q&A 목록을 함께 읽고, 내 말로 바꿔 말할 수 있는 답변 초안을 작성합니다. 사용할 제공업체는 직접 고르고, API 키도 직접 관리합니다.

**양방향 실시간 번역.** 통화 양쪽의 말을 들리는 즉시 번역하며, 두 방향 모두 지원합니다. 상대의 말을 이해하고, 편한 언어로 답할 수 있습니다.

**내 목소리.** 10초에서 60초 분량의 목소리를 녹음하면 Talkaside가 로컬에 음성 프로필을 만듭니다. 이 프로필은 내가 보내는 번역 음성에만 사용됩니다. 이 기능에는 NVIDIA GPU가 필요합니다.

**로컬 기록.** 텍스트 기록과 세션은 내 PC의 `%LOCALAPPDATA%\Talkaside` 폴더에 저장됩니다. 통화 녹음은 선택 사항이며, 켜기 전까지는 꺼져 있습니다.

**플로팅 패널.** 항상 맨 위에 떠 있는 작은 창으로, 통화 창 옆에 답변 제안을 보여 줍니다. 지원되는 화면 캡처에는 나타나지 않도록 만들어져 있어서, 화면을 공유해도 내 메모는 보이지 않습니다. 캡처 도구마다 동작이 다르므로, 중요한 통화 전에 사용하는 도구로 꼭 확인하세요. 어시스턴트 사용을 감지할 수 없게 만들지 않으며, 그럴 목적으로 만든 것도 아닙니다.

## 개인정보 보호

Talkaside는 음성 처리 경로에 자체 서버를 두지 않습니다. 음성과 텍스트는 설정한 음성 인식 및 AI 제공업체에만 전송되며, 다른 곳으로는 보내지 않습니다. 제공업체는 보낸 내용을 볼 수 있으므로 신중하게 선택하세요.

## 시스템 요구 사항과 가격

- Windows 10 또는 11, 64비트. macOS, Linux, 모바일 버전은 없습니다.
- 5일 데모는 무료입니다. 활성화는 Windows 기기 한 대당 한 번입니다.
- 유료 라이선스는 7일, 30일, 1년 기간으로 제공됩니다.
- 클라우드 AI와 음성 인식 요금은 연결한 제공업체가 따로 청구합니다.
- 설치 파일에 코드 서명이 없으므로, 처음 실행할 때 Windows SmartScreen 경고가 나타날 수 있습니다.
